## 🛡️ Production Replacement Procedure
1. **Manufacturer Press Portals**: Acquire official press kit photography from Royal Enfield Media, TVS Press, Bajaj Auto Newsroom, Maruti Suzuki Media, Toyota Bharat, etc.
2. **Rental Partner Ingestion**: Contracted TBH fleet partners upload actual high-definition photographs of their registered rental fleet units during unit onboarding.
3. **Commercial Database Migration**: Update `vehicle_media` table in MySQL:
   ```sql
   UPDATE vehicle_media SET
       license_type = 'COMMERCIAL_PARTNER_LICENSE',
       verification_status = 'COMMERCIALLY_VERIFIED',
       verified = true,
       verified_at = NOW()
   WHERE vehicle_model_id = :id;
   ```
